プライバシーポリシー

収集する情報
ニックネーム、アイコンの色・画像、投稿したレビューや評価、利用履歴、お問い合わせ内容を収集することがあります。

利用目的
本サービスの提供・維持・改善、不正利用の防止、お問い合わせへの対応のために利用します。

第三者提供
法令に基づく場合を除き、収集した情報を第三者に提供することはありません。

匿名の利用傾向データについて
当サイトでは、サービスの向上および統計的分析を目的として、個人を特定しない形(匿名化されたアクセスログ・検索傾向)のデータを収集・利用する場合があります。

外部データの利用について
本サービスの作品情報・画像の一部は、The Movie Database (TMDB) のAPIを利用して取得しています。本サービスはTMDBによる承認・認定を受けたものではありません(This product uses the TMDB API but is not endorsed or certified by TMDB)。「みんなの愛度」の初期値には、まだ投票が少ない作品について参考情報としてTMDBの評価を一部反映している場合があります。小説・漫画の情報の一部は楽天ブックス書籍検索APIを、音楽の情報の一部はiTunes Search APIを利用して取得しています。

これは簡易版の掲載です。詳しい内容や最新の状態については、随時見直しを行っています。
